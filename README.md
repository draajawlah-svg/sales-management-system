# نظام إدارة المبيعات

تطبيق محلي على Windows لتتبع المبيعات، العملاء، المنتجات، وإدارة المخزون باستخدام Electron + React + SQLite.

## المتطلبات
- Node.js 18 أو أحدث
- npm

## التشغيل
```bash
npm install
npm run dev
```

## إنشاء ملف نصب
```bash
npm run build
```

## المميزات
- لوحة تحكم
- إدارة المنتجات
- إدارة العملاء
- إنشاء فواتير البيع
- متابعة سجل المبيعات
- قاعدة بيانات محلية SQLite

## ملاحظات
هذا مشروع MVP عملي ومناسب للاستخدام الشخصي على جهاز Windows، ويمكن تطويره لاحقًا لتضمين الخصومات والتقارير والإدارة المتقدمة.
